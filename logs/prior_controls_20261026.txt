Methodological Reporting Notes:
  1. Depth-3 Diagnostic Reading: Depth 3 has 150 transitions from 25 synthetic programs.
     Because transitions within a program are not independent, the 37.3% vs 32.8% difference
     is reported descriptively with no statistical superiority claim.
  2. Heap Keys: Unified tuple key (depth, len(prims), is_partial, tuple(prims), item_counter)
     used throughout, guaranteeing strict type safety under score ties.
  3. Backoff Labels: Tracked once per slot expansion decision (D1_context, D2_slot, D3_uniform),
     not per-option candidate lookup.
  4. Hidden Suite: All solutions verified 20/20 against pure-Python references on pinned inputs.
  5. Free vs. Priced Close Invariance: Condition 4 and Condition 5 are equivalent by construction
     because every valid candidate program performs exactly one leaf-closure action (xs),
     shifting all complete program scores by constant -lambda and preserving relative priority.
  6. Type-Conditioning Dominance: In this typed DSL, ScalarOp, Predicate, and Reducer slots belong
     to exactly one parent combinator, so type validity alone enforces parent-combinator matching;
     transition context only influences ListExpr combinator-to-combinator nesting.
